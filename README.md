# GatherForProfessions

**ProfessionPlanner**, a WoW Forever addon that helps you level professions
across all characters on your account: what to craft next, what you already
have (bags, bank, alts, Warband bank), and what is missing and where to get it.

Professions: Mining, Blacksmithing, Tailoring, Leatherworking and Enchanting.

**Download:** see [Releases](../../releases). The addon is in beta, so please
report problems under [Issues](../../issues).

Installation, commands and how the data works: [ProfessionPlanner/README.md](ProfessionPlanner/README.md).

Leveling data is based on <https://www.wow-professions.com/forever> and
<https://www.wowhead.com/forever/>.
